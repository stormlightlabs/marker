# Marker Branding Notes

## Wordmark typography

Use **Righteous** for the Marker logo/wordmark across product surfaces.

- Extension: both minimal and retro themes should use Righteous for `.wordmark` / brand lockups. Other headings may remain theme-specific.
- Website: add Righteous to the font stack and apply it to the text wordmark in the header/footer brand lockups. Keep existing Sora/Lora for product copy unless a broader redesign changes that.
- Mobile app: bundle Righteous as a Flutter font asset and use it for the app wordmark, splash/empty-state brand moments, and any explicit Marker logo text. Keep Cupertino/system text for UI controls and reading surfaces.

The intent is to make "Marker" recognizable without forcing every heading into the display face.
